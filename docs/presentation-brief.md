## The claim, in one sentence

A 1.01M-parameter CNN trained from scratch matches ImageNet-pretrained detectors
4–20× larger (MobileNetV3-Small, EfficientNet-B0, Xception) on StyleGAN2-vs-FFHQ
detection, at the lowest latency and among the lowest memory of the four,
measured on the identical task, same GPU, same session — and its cost is
generalisation: 0.70 on an unseen generator where the pretrained models score
0.96–0.99. (Edge deployment was dropped from the scope by the panel; the claim
is resource comparison.)

## The numbers (as of 2026-09-28; README is authoritative)

**Headline** `test19_sg2_crop_no_fft`: five plain 3×3 conv blocks (32-64-128-256-256),
Dense 128, Dropout 0.4, sigmoid. Native-resolution 256² crops, no resize.
- test AUC **0.9998 ± 0.0002** over seeds 42/43/44 (0.9996 / 0.9998 / 0.99995); accuracy 0.99–0.997

**The accuracy story (the spine of the talk)** — README "Results", `docs/learnings.md`:
1. First result 0.9995 was a **shortcut**: reals 512², fakes 1024². Found by auditing file properties (`audit_dataset.py`).
2. Clean data, both 1024², resized to 256²: **0.964**. The resize deletes the GAN fingerprint (post-resize high-frequency AUC 0.52).
3. Native crops, no resize: **0.9996**. Same model, same input size, same latency.
4. Checked it is not a new shortcut: native-resolution audit 0.55; JPEG q95 costs 0.001–0.002; unseen FFHQ reals scored correctly; StyleGAN3 collapse proves the signal is a real generator fingerprint, not a leak.

**Ablations / negatives** (all recorded):
- FFT branch: 0 on the mix, +0.011 on resized SG2, 0 on crops, +0.008 on SG3-T → dropped.
- Offline distillation (test18/18c): worse than hard labels (0.923 / 0.901 vs 0.964) — inconsistent teacher/student views (Beyer et al. 2022).
- Stride-2 stem: −0.001 AUC for 4× fewer MACs, half the CPU latency; slower to train (130 vs ~10 epochs).
- Peak memory was first reported as 1,301 MB; it was cuDNN autotune scratch; corrected to 171 MB with both numbers kept.
- Operating condition: native-resolution input only — chance (0.556) on downscaled input.

**Generalisation phase (IN PROGRESS — check README "Held-out generator" table before slides):**
- Wang 2020 augmentation from scratch: never learned. Warm-started from the headline: SG3-R 0.742 → 0.772 (small, real).
- Two generators (SG1+SG2) needed batch norm to start training (test23c): SG3-R 0.742 → 0.777 (small, same size as the augmentation's).
- Online distillation from EfficientNet-B0 (test25, consistent views): SG2 0.9987 but SG3-R **0.666 — worse than hard labels**. The student copies decisions, not the ImageNet representation (Ojha 2023).
- Scale augmentation (test24): downscaled-input probe 0.556 → **0.746** (the lever's target), native 0.9982, SG3-R 0.715. Scale robustness and generalisation are separate axes.
- All four levers done: +0.03, +0.035, −0.08, −0.03 on SG3-R. Reading: at 1M params from scratch, generalisation to StyleGAN3 is not recoverable by training tricks; the gap is representational.
- Still to run: test26 (Wang aug stacked on the two-generator model), int8 quantization of all four.
- Selection set = StyleGAN3-R; final test = StyleGAN3-T, scored once.

## Q&A the panel is likely to ask (answers in README/learnings)

1. Why is a plain 5-layer CNN enough? — In-distribution detection is saturated for every architecture (all four ≥0.9998); the contribution is cost and the pipeline finding, not the architecture.
2. Isn't 0.9998 a shortcut? — The chain above; audit, JPEG, held-out reals, SG3 collapse.
3. Why worse on memory/MACs than MobileNet? — 12% more memory at bs=1 (171 vs 152), 16× MACs because the first layer runs at full resolution; stride-2 variant tested: 4× fewer MACs for −0.001 AUC; Gragnaniello 2021 on early downsampling.
4. Why does it fail on StyleGAN3? — From-scratch features are StyleGAN2's fingerprint; ImageNet features transfer (Ojha 2023). Measured against three baselines; levers tried.
5. Why no hyperparameter sweep? — Values that changed results were tested (pipeline, patience, stem, aug, BN); accuracy saturated so lr/batch sweeps cannot change a conclusion; sensitivity runs listed as owed.
6. One seed? — Three seeds, ±0.0002.
7. Latency on what hardware? — L4, same session, median of 1,000, protocol in README; CPU secondary; no phone measurement, deployment out of scope.
8. Why did you drop the FFT branch? — Four-way ablation, all zero.
9. Why 25k per class? — Budget; Bouthillier 2021; three seeds show stability.
10. What is the novelty? — Not the architecture: the measured resource comparison on an identical task, the resize/crop finding that lifted every model, the honest generalisation accounting, and (if it lands) a training-only lever at fixed cost.
